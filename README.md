# My memories
A simple picture-and-title collection with All, Games, Shows, Food, and Everyday things filters. Each item links to its own HTML page with a photo gallery and a collapsed Details section. Click a photo to open it at full size. Category selection is kept when returning to the collection.

## Publish on GitHub Pages
Upload these files to a GitHub repository. In Settings → Pages, select Deploy from a branch → main → / (root).

## Add memories
Edit script.js. Each memory has a category, title, text, and optional reference link. Add its picture path to the pictures map. Add a short title and note to the titles and notes maps. Pictures are stored in images/. Create a matching item HTML page for each new entry, using an existing item page as a template. Additional reference pictures come from the same image sources listed below.

## Default item layout
Every item page uses an outer Details dropdown, containing a nested My notes dropdown for personal recollections. Keep research, identification status, and references outside My notes but inside Details. Both dropdowns start closed. Use this structure for every new item page.
